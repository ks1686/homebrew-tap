# ks1686/tap

Homebrew tap for [genv](https://github.com/ks1686/genv) and [peaproxy](https://github.com/ks1686/peaproxy). Both are distributed as casks that install prebuilt binaries for macOS and Linux (Intel and ARM).

## Install

```bash
brew tap ks1686/tap
brew install --cask genv
brew install --cask peaproxy
```

Or without tapping first: `brew install --cask ks1686/tap/genv`.

- **genv**: track, sync, and reproduce your software environment across machines
- **peaproxy**: localhost multi-provider AI gateway (API keys, local runtimes, optional subscription OAuth)

Upgrade with `brew upgrade --cask genv peaproxy`.

## How the casks are updated

The files in `Casks/` are generated by GoReleaser in each project's release workflow, which commits a new version here (as `goreleaserbot`) for every stable tag. Do not edit them by hand; change the `homebrew_casks` section of the project's `.goreleaser.yml` instead.

`.github/workflows/audit.yml` runs `brew audit --cask --strict --online` and installs both casks on Linux and macOS for every change and weekly.
