# ks1686/tap

Homebrew tap for [genv](https://github.com/ks1686/genv), [peaproxy](https://github.com/ks1686/peaproxy), and [umbilical](https://github.com/ks1686/umbilical). [genv](https://peapod.fyi/genv/) and [peaproxy](https://peapod.fyi/peaproxy/) are distributed as casks that install prebuilt binaries for macOS and Linux (Intel and ARM); [umbilical](https://peapod.fyi/umbilical/) is a native macOS download manager over aria2 and yt-dlp, and is macOS only (14 Sonoma or later).

## Install

```bash
brew tap ks1686/tap
brew install --cask genv
brew install --cask peaproxy
brew install --cask umbilical
```

Or without tapping first: `brew install --cask ks1686/tap/genv`.

- **genv**: track, sync, and reproduce your software environment across machines
- **peaproxy**: localhost multi-provider AI gateway (API keys, local runtimes, optional subscription OAuth)
- **umbilical**: native macOS download manager over aria2 and yt-dlp

Upgrade with `brew upgrade --cask genv peaproxy umbilical`.

## How the casks are updated

The genv and peaproxy files in `Casks/` are generated by GoReleaser in each project's release workflow, which commits a new version here (as `goreleaserbot`) for every stable tag. Do not edit those by hand; change the `homebrew_casks` section of the project's `.goreleaser.yml` instead.

The umbilical cask is not generated by GoReleaser. The app is a native Swift release; each GitHub release includes an `umbilical.rb` asset that is copied into `Casks/` by hand.

`.github/workflows/audit.yml` runs `brew audit --cask --strict --online` on genv and peaproxy, then installs those two casks and runs their binaries, on Linux and macOS, for every change and weekly. It does not audit or install umbilical.
