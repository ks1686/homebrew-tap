# ks1686/tap

Homebrew tap for [genv](https://github.com/ks1686/genv), the cross-platform environment manager.

## Install

```bash
brew tap ks1686/tap
brew install --cask genv
```

Formulae live under `Casks/`. Cask updates are published from the genv release workflow.
