# ks1686/tap

Homebrew tap for [genv](https://github.com/ks1686/genv) and [peaproxy](https://github.com/ks1686/peaproxy).

## Install

```bash
brew tap ks1686/tap
brew install --cask genv
brew install --cask peaproxy
```

- **genv** — cross-platform environment manager
- **peaproxy** — localhost AI gateway (API keys and optional subscription OAuth)

Formulae live under `Casks/`. Cask updates are published from each project's release workflow.
